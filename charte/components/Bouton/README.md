# Bouton

Bouton en pilule, le libellé commence par un verbe : « Écrire ma réponse », « Inviter Thomas ».

- `variante="principal"` (rouge) : l'action que tu fais, une seule par écran.
- `variante="secondaire"` (bleu) : ce qui concerne l'autre (inviter, relancer).
- `variante="discret"` : refuser, passer, revenir.
- Accepte toutes les propriétés d'un `<button>` (`onClick`, `disabled`…).
