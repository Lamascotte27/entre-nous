# Logo

Le logo est le mot « entre nous » en Caprasimo, avec Point (bleu) et Virgule (rouge) glissés entre les deux mots comme un point-virgule.

- `variante="logo"` (par défaut) : le logo complet. `variante="signe"` : le point-virgule seul, pour l'icône, les badges, le favicon.
- `hauteur` en pixels. Le mot prend la couleur du texte (`currentColor`) ; Point et Virgule gardent `bleu` et `rouge`.
- `inverse` : Point passe en papier pour un fond `bleu`. `mono` : tout en `currentColor`, pour la gravure, le tampon, un fond `beurre`.
- `fixe` : couleurs de marque figées, quel que soit le thème (icône d'app dans une notification).

À faire : laisser autour du logo une marge égale à la hauteur de Point. Ne jamais remplacer le point-virgule par le caractère « ; » d'une police. Ne pas ajouter de contour ni d'ombre.
