# NotificationPush

Maquette d'une notification, pour les captures d'App Store, les vidéos et la relecture des textes.

- `texte` (obligatoire), `heure` (« maintenant » par défaut), `titre` (« Entre nous » par défaut).
- Une notification ne contient jamais le texte d'une réponse : elle dit qui a répondu, pas quoi.
