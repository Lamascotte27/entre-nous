# Billet

Une réponse, présentée comme un petit mot posé sur la table : fond craie, coins presque carrés, légère rotation, signature en italique.

- `auteur="toi"` (par défaut) : incliné vers la gauche, signé en rouge. `auteur="autre"` : incliné vers la droite, signé en bleu.
- `prenom` pour la signature, le texte en enfant.
- `scelle` : affiche le cachet et « Billet scellé jusqu'à ta réponse », sans jamais afficher le texte.
- Sans texte, le billet de toi devient une invite : « Écris ta réponse… ».
