# CarteOffre

Une offre d'abonnement dans le paywall. Un abonnement couvre les deux partenaires.

- `titre`, `detail`, `prix`, `mention` (la base du prix : « par personne et par mois »), `etiquette` (une seule par paywall), `choisie`, `onClick`.
- S'utilise en groupe, comme des boutons radio : une seule carte `choisie` à la fois.
- Prix toujours TTC, en euros, avec la virgule française.
